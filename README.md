# Pathora Intelligence
### An Intelligent System for Job Market Analysis, Salary Forecasting and Skill Gap Assessment

**Tagline:** Turning Career Data into Smarter Decisions.

## Project Overview
Pathora Intelligence is a data-driven career analytics project designed to explore job market information, analyze career-related factors, and predict salary categories using machine learning.

The project combines SQL, Python, Machine Learning, Power BI, and a Flask-based web application.

## Technologies Used
- **Database:** MySQL
- **Programming:** Python
- **Data Analysis:** Pandas, NumPy, Matplotlib, Seaborn
- **Machine Learning:** Classification algorithms
- **Visualization:** Power BI
- **Web Development:** Flask, HTML, CSS

## Project Modules

### 1. SQL Analysis
- Database and table creation
- Dataset import and validation
- SQL queries for job market analysis

### 2. Python Analysis
- Data loading and exploration
- Data preprocessing
- Exploratory Data Analysis (EDA)
- Data visualization
- Machine learning model development

### 3. Machine Learning
- Salary classification
- Model training and evaluation
- Salary prediction using the trained model

### 4. Power BI Dashboard
An interactive Power BI dashboard created to present job market insights and career-related analysis.

## How to Run the Web Application
1. Open the project folder in VS Code.
2. Open the terminal.
3. Navigate to the Python folder.
4. Run:

```bash
python app.py
```

5. Open the local URL displayed in the terminal in your browser.
